# Zero-Rated Hosts Scanner (Tanzania)

Webapp + Android scanner for discovering approximate zero-rated hosts on Tanzanian mobile networks (Vodacom, Airtel, Yas, Halotel).

## Live Demo

Static dashboard is served from this repository root (`index.html`).

## Features
- Select network (Vodacom / Airtel / Yas / Halotel)
- Search hosts
- Report new hosts (localStorage)
- About + disclaimer

## Disclaimer

Detection is approximate only. Operators use DPI/SNI. Results are not guaranteed. Use at your own risk.
